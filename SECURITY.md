# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |

## Reporting a Vulnerability

Voidrock is a fully client-side static site: it collects no data,
makes no network requests, and stores only a best score in
`localStorage`. The attack surface is correspondingly small, but
issues are still taken seriously.

Please report suspected vulnerabilities privately via
[GitHub security advisories](https://github.com/szuck12/voidrock/security/advisories/new)
rather than opening a public issue. Include a description, the
affected file(s), and steps to reproduce.

You can expect an initial response within 7 days. Once a fix is
released, the advisory will be disclosed and credited in
CHANGELOG.md unless you prefer to remain anonymous.
